01

Konsep Dasar

Memahami ekosistem AI melalui analogi sehari-hari

AI Eksternal

AI Cloud
= Naik Taksi

Infrastruktur dimiliki & dikelola penyedia (AWS, Google, Azure). Anda cukup bayar pakai.

  • Tanpa investasi awal — tidak perlu beli server atau GPU Langsung pakai dalam hitungan menit
  • Skalabilitas instan — dari 10 ke 1 juta pengguna otomatis
  • Model AI terkuat di dunia — GPT-4, Claude, Gemini
  • Bayar sesuai pemakaian — per token, per API call
☁️ Server Penyedia
AWS · Google · Azure
⬆⬇
⚠ Data melintas internet publik
⬆⬇
🏢 Organisasi Anda

RISIKO UTAMA

Data sensitif dikirim ke server asing. Bergantung koneksi internet. Biaya naik eksponensial saat volume tinggi.

AI Internal

AI Lokal
= Punya Mobil Sendiri

AI berjalan di atas perangkat keras milik organisasi. Data tidak pernah keluar.

  • Privasi absolut — data tidak pernah meninggalkan kantor Wajib untuk data medis, hukum, keuangan
  • Latensi nol — respons instan, bekerja tanpa internet
  • Kontrol penuh — modifikasi model sesuai kebutuhan spesifik
  • Biaya tetap — tidak ada tagihan per-token yang mengejutkan

Infrastruktur

Anatomi Perangkat Keras AI

🧠

CPU

Manajer proyek cerdas — bisa banyak tugas tapi hanya beberapa sekaligus. Tidak cukup untuk AI berat.

⚡

GPU

Ribuan "pekerja pabrik" paralel. Wajib untuk training dan inference AI. Komponen termahal AI lokal.

🔬

NPU (Chip AI)

Chip khusus AI di laptop modern (Copilot+ PC). Hemat daya, cukup untuk model kecil sehari-hari tanpa server.

💡 Model populer untuk lokal: Llama 3 (Meta) · Mistral · Qwen (Alibaba) · Phi (Microsoft) — bisa berjalan di komputer biasa dengan RAM 8–16GB untuk tugas ringan

☁️ Cloud: Biaya di Belakang

Murah di awal. Biaya naik seiring volume. Cocok untuk volume kecil atau beban kerja tidak teratur dan tidak dapat diprediksi.

🖥️ Lokal: Biaya di Depan

Mahal di awal (GPU, cooling, SDM). Setelah modal balik, biaya operasional sangat rendah meskipun volume tak terbatas.

⚠️ Waspadai vendor lock-in: Ratusan jam prompt engineering di satu platform cloud akan menyulitkan migrasi ke provider lain di masa depan.

04

Privasi & Regulasi

Kedaulatan data di Nusantara

Kerangka Hukum Indonesia

Regulasi yang Wajib Dipatuhi

⚖️

UU PDP No. 27/2022

Hak subjek data dan kewajiban pengelola. Berlaku untuk semua entitas yang berdampak pada penduduk Indonesia — termasuk algoritma AI.

📱

UU ITE No. 19/2016

Mengatur transaksi elektronik dan informasi digital, termasuk perlakuan data oleh sistem otomatis dan kecerdasan buatan.

🌍

GDPR (Referensi Global)

Kerangka Uni Eropa yang berlaku jika data warga EU diproses. Mengirim data ke cloud asing dapat memicu kewajiban Pasal 28.

🚨 Contoh Pelanggaran Nyata: Ketika staf HR menyalin daftar kandidat berisi NIK ke chatbot cloud untuk diringkas — secara hukum mereka telah mengirim data pribadi ke negara ketiga tanpa izin, melanggar UU PDP.

Risiko Strategis

Ancaman yang Sering Diabaikan

  • Kebocoran Kekayaan Intelektual (IP Leak) Cetak biru teknologi yang dikirim ke cloud komersial terpapar langsung kepada entitas penyedia — meskipun ada perjanjian kerahasiaan
  • Ketergantungan Penyedia (Vendor Lock-in) Jika API cloud tumbang atau harga naik sepihak, seluruh sistem otomatis organisasi bisa mati seketika tanpa peringatan
  • Kerentanan Rantai Pasok (NIS2 Eropa 2024) Regulasi terbaru mengklasifikasikan API cloud eksternal sebagai titik kerentanan supply chain yang harus diaudit
  • Risiko Tersembunyi AI Lokal: Backup Cloud File percakapan AI lokal (.json) sering tersinkronisasi otomatis ke Google Drive/Dropbox/OneDrive — menganulir seluruh upaya privasi lokal

Personalisasi
vs Etika Data

  • Pemantauan Kemajuan Murid → Cloud Hyper-personalization tingkat soal secara real-time
  • Data Pribadi & Penilaian Esai → Lokal Wajib Tidak boleh disedot ke cloud komersial

Sektor Ritel & Pemerintah

🛒 Ritel — AI Cloud

Menganalisis jutaan data pergerakan selera konsumen dan ramalan iklim untuk optimasi stok sebelum musim pembelian. Kamera AI mandiri (Edge Vision) menghitung stok etalase otomatis.

💬 Asisten Produk 24/7

AI cloud menjawab pertanyaan produk kapan pun tanpa jemu. Rekomendasi personal meningkatkan konversi vs pencarian manual standar.

Platform pencarian cerdas berbasis Retrieval-Augmented Generation (RAG) mengubah gudang dokumen kewilayahan yang terpisah-pisah menjadi sumber pelayanan publik yang dinamis.

  • Menghancurkan sekat administratif antar departemen
  • Dokumen statis → sumber informasi dinamis
  • Publik dapat navigasi data tanpa tumpukan map laci

Framework Perutean

Tugas Mana ke Mana?

Jenis Tugas Rekomendasi Alasan Utama
Ekstraksi data faktur harian AI Lokal Data finansial privat + volume tinggi + komputasi ringan
Analisis dokumen legal kompleks Hibrida Privat Perlu penalaran dalam + data klien rahasia
Pembuatan gambar iklan kampanye Cloud Frontier Model raksasa cloud terbaik; tidak ada data sensitif
Klasifikasi sentimen ulasan massal Lokal Volume Tinggi Tugas ringan, volume raksasa → hemat per-token

Riset saintifik & sintesis jurnal Cloud Frontier Membutuhkan kapasitas penalaran otak raksasa
Arsitektur Hibrida

Cara Kerja Sistem Hibrida

🔍

1. Gatekeeper Lokal

Model kecil (Phi/Qwen) berjalan terus 24/7 di server on-premise. Menyaring dan mengklasifikasikan setiap permintaan masuk.

⚙️

2. Proses Lokal

Tugas sensitif & berulang diproses langsung di infrastruktur internal. Data tidak pernah keluar.

🚀

3. Kirim ke Cloud

Hanya tugas non-sensitif yang berat dikirim ke frontier models. Gatekeeper membuka jalur hanya untuk data yang aman.

💡 Teknologi Orkestra: vLLM sebagai sistem operasi manajemen beban paralel · Azure/Bedrock untuk managed private cloud · Edge NPU untuk perangkat pengguna

Tantangan Lokal

AI yang benar-benar memahami Indonesia

Tantangan Bahasa

AI yang Paham
Nusantara

Model global dibangun atas data bahasa Inggris. Tanpa konteks lokal, AI hanya memberikan "terjemahan kosong".

  • 700+ bahasa daerah hampir tidak ada dalam dataset global
  • Bahasa informal & gaul tidak dipahami model asing
  • Konteks budaya lokal sering menghasilkan respons rancu

Dataset Terbuka Indonesia

  • OSCAR — miliaran token domain web domestik Indonesia
  • CC-100 — arsip web komprehensif Bahasa Indonesia
  • IndoNLI — parameter nalar natural language inferencing
  • Wikipedia Indonesia — ensiklopedia lokal terstruktur
  • Kaskus Archive — bahasa gaul & percakapan informal nyata

🎯 Menyematkan dataset lokal ini adalah prasyarat mutlak agar AI benar-benar melayani warga Indonesia — bukan sekadar terjemahan bertenaga GPU.
